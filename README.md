# LineNest

导入图片，点击添加横竖分割线，快速切分矩形素材。

## 开发

需要 Node.js 22.12+ 和 pnpm。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址。首页路径为 `/`，编辑器路径为 `/editor`。编辑器标识菜单可返回首页；页面内切换保留当前图片、线条、模板选区和撤销记录。

## 检查与构建

```sh
pnpm typecheck
pnpm build
pnpm preview
```

图片在浏览器本地处理，不上传服务器。

## 当前功能

- 导入或拖入 PNG、JPG、WebP、AVIF 图片，单张不超过 40 MB。
- 未导入图片时，整个工作台以模糊遮罩呈现，左侧显示拖入提示，右侧提供红底白字、白图标的上传按钮，左上角可返回首页；背景工具和快捷键不可操作，支持直接拖入图片。导入成功后，遮罩和专用返回入口一起消失。
- 工作台采用白底、黑灰文字和红色强调色；顶栏、侧栏、刻度尺、浮动控件及菜单弹窗统一使用中性配色，画布保留浅灰点阵。
- 右下角视图工具栏提供“图片向右旋转 90°”，所有工具模式均可使用。图片、线条、组群和裁剪选区整体顺时针旋转，宽高互换并自动适应画布，保留当前模式、对象选择和锁定状态；每次旋转支持一步撤销和重做，导出使用旋转后的图片，模板仅保存旋转后的线条布局和尺寸。
- 导入图片后默认进入分割线模式：左键单击图片添加贯穿图片的竖线；按住 W 再单击添加横线，松开 W 恢复竖线。按 S 或点击工具栏可重新进入此模式。
- 分割线落下后，可在最新选中线条的虚线框范围内按住左键拖动，横线上下移动、竖线左右移动；松开确认，支持撤销和重做。框外按原规则新建线条，新线自动选中，旧线不能再通过此方式拖动；调整其他线条仍可切换选择模式。
- 分割位置取整到原图像素，图片外和边缘不新增线条；同位置的同方向分割线不会重复添加。右键保留对象操作菜单。
- 按 V 切换选择模式拖动微调：横线只能上下移动，竖线只能左右移动，位置限制在图片范围内，始终贯穿图片。支持方向键微调、删除、撤销和重做；分割线及包含分割线的组群不支持旋转或镜像，也不显示端点编辑柄。
- 画布顶部和左侧显示原图像素刻度尺，随缩放、平移同步更新；刻度尺仅用于参考，点击图片落线。
- 横竖分割线在所有工具模式下延伸至可见画布边缘，图片外的延长部分也支持选择、框选和拖动。线条使用白色底描边加深灰或红色主线，在相近颜色的图片上仍可辨认；显示宽度不随缩放改变，图片外的延长部分不参与切图或模板坐标。
- 画布左上角持续显示当前模式和操作提示。按住空格临时切换到拖动画布，按住左键移动图片与分割线的整体视图；松开空格立即结束临时拖动，恢复原模式，不修改图片或线条坐标。
- 手动画线、拖动线身整条移动、拖动端点、单选、Shift 多选、框选和全选。选择工具和画线工具均可拖动已有线条，画线工具在空白处拖动可继续画线。
- 自由画线可以从图片外的画布空白处起拖，预览和已有自由线条仅显示图片范围内的部分；保留原始端点和方向，完全未经过图片的拖动画线不会创建对象。
- 编组、嵌套编组、解组、组内编辑和锁定。
- 整组复制、移动、水平或垂直镜像、指定角度旋转、批量删除。
- 拖动选框上方的圆形旋转柄可整体旋转；画布右键提供编组、复制、镜像等操作；顶栏支持收起对象面板。
- 撤销和重做，最近 100 步；选择变化也计入历史。
- 框选矩形裁剪区域，按原图像素导出 PNG，不带编辑线条。
- 按实际线段切图，预览并勾选区域后打包下载 ZIP，包含 PNG 与原图位置清单。支持斜线、交点、封闭区域及孔洞，非矩形部分透明。
- 右侧提供“模板 / 图层”标签栏，默认显示模板及数量，可直接新增。IndexedDB 仅保存线条、分组及布局尺寸，不保存原图、图片缩略图、裁剪或区域标记；支持套用、重命名、删除和文件备份，预览由线条实时绘制。旧版模板会自动迁移并清除持久化的图片数据。
- 油漆桶（B）用于标记需要裁切的区域，可自定义颜色和 0–100% 不透明度。单击闭合区域添加标记，同一区域重填会替换设置；“清除标记”后单击区域可移除最上层标记，右键保留对象菜单，Ctrl + Z 撤销。按住空格仍可临时平移。
- 标记是独立遮罩，保存当时的区域形状；移动或删除分割线后不会改变已有标记，可清除后重新标记。整图旋转时标记同步旋转；模板不保存这些标记，套用模板时保留当前标记。
- “导出 → 导出已标记区域”仅裁出标记的块，每块一张 PNG 并打包 ZIP；导出保持原图颜色，不包含提示遮罩。没有标记时该入口禁用，原有“按线切图”入口继续提供全部分区。存在裁剪选区时只输出两者的有效交集，完全在范围外的标记不生成空白文件。
- 模板仅用于“套用”，没有图片时禁用套用及文件导入。套用仅替换线条与分组，保留当前图片、裁剪选区和区域标记，并支持撤销。尺寸不同时先提示，按原坐标套用自由线条、不缩放；分割线保留方向和分割坐标，重新贯穿当前图片。旧版备份只提取线条，不读取或恢复内嵌图片。

复制后的对象与原对象重叠，保持选中，直接拖走即可。没有自动间距、排列或吸附。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 分割线模式（默认） | S |
| 添加竖向 / 横向分割线 | 分割线模式中左键单击 / 按住 W + 左键单击 |
| 选择 / 拖动画布 / 画线 / 裁剪 | V / H / L / C |
| 油漆桶 · 标记裁切区域 | B |
| 多选 | Shift + 点击 |
| 全选当前层 | Ctrl + A |
| 编组 / 解组 | Ctrl + G / Ctrl + Shift + G |
| 复制 | Ctrl + D |
| 进入组内 / 退出一层 | 双击或 Enter / Esc |
| 删除 | Delete / Backspace |
| 撤销 / 重做 | Ctrl + Z / Ctrl + Shift + Z 或 Ctrl + Y |
| 移动 1 px / 10 px | 方向键 / Shift + 方向键 |
| 缩放 / 平移 | 滚轮 / H 后左键拖动、空格 + 拖动或鼠标中键拖动 |

macOS 使用 Command 替代 Ctrl。输入框内保留文字编辑快捷键。

## 手动验收顺序

先验收无图片的工作台入口：

1. 刷新后直接进入 `/editor`，确认整个工作台背景模糊，前景为左侧提示、右侧上传图标的分栏布局，没有边框卡片或提示弹窗，下方仅说明支持的图片类型。
2. 按 Tab，确认不能聚焦背景按钮；按 S、V、H、L、C 等编辑快捷键，不应操作背景工具。
3. 点击右侧上传图标并取消文件选择，界面应保持原状；再次选择受支持图片，确认遮罩消失并进入分割线模式。
4. 重新刷新进入空工作台，直接拖入一张图片，确认提示变为松开导入，不出现另一套提示层；将文件拖出工作台，应恢复原提示。
5. 选择或拖入不支持的文件，确认仍能重新选择图片；导入后再替换带有线条的图片，应保留原有替换确认。
6. 首次导入后按 Ctrl + Z 撤销到无图片状态，再按 Ctrl + Shift + Z 或 Ctrl + Y，确认可以重做恢复图片。
7. 导入图片后检查顶栏、工具栏、右侧面板、刻度尺和缩放条均为白底；打开模板、导出菜单和画布右键菜单，确认弹层没有米黄色底色。自由画线的旋转手柄应为白底红边，切图预览中未选区域使用中性灰；返回首页，确认首页配色保持原样。
8. 未导入图片时，确认右侧上传入口为图标与文字横排的红底白字按钮，并与左侧标题、描述、格式说明组成的完整文字区垂直居中；左上角“返回首页”也为红底、白字、白箭头，可点击或通过键盘激活。再次进入工作台后选择图片，确认遮罩和这处返回入口消失，工作台原有导航正常。

先验收分割线模式：

1. 导入素材图，确认默认选中分割线工具，顶部和左侧显示像素刻度。
2. 在图片内部连续单击三个不同位置，确认立即出现三条贯穿图片的竖线，无需拖动；同一位置重复点击不新增重叠线。
3. 按住 W，在两个不同高度单击，确认出现两条横线，与三条竖线形成 12 个矩形区域；松开 W 再单击应恢复竖线。切换窗口再回来，确认 W 不会卡住。
4. 点击图片外围空白、刻度尺和图片边缘，确认不新增分割线；右键只打开对象菜单。
5. 按 V，分别斜向拖动横线和竖线，确认横线仅上下移动、竖线仅左右移动，预览与松开后位置一致，始终连接图片两侧，拖出图片时限制在边界。
6. 用方向键、Shift + 方向键微调，再删除、撤销和重做，确认位置和方向正确；旋转、镜像和端点拖动不可用于分割线。
7. 缩放和平移后检查刻度仍对齐图片坐标，再按 S 点击，确认落线位置正确；按 H 或空格拖动不能误加线。
8. 使用“导出 → 按线切图”检查矩形区域；保存、套用和备份导入模板，确认分割线仍保持贯穿约束；套用到不同尺寸图片时检查延伸范围和边界限制。
9. 检查左上角默认显示“分割线模式”；按住空格，应显示“临时拖动画布”，鼠标变抓手。按住左键拖动后先松开空格，确认视图停止移动，模式恢复；松开鼠标后再次单击应正常添加分割线，临时平移不应增加或移动线条对象。
10. 点击左侧选择、画线或裁剪按钮后，直接按住空格拖动画布，松开后应返回对应模式；点击缩放按钮后也可使用空格临时平移。输入框、模板面板内的空格仍保持正常输入和操作，切换窗口后抓手状态不应卡住。
11. 创建横竖分割线，确认图片外仍能看到它们并延伸至画布边缘。按 V 后从图片外点击、框选和拖动延长线，图片内外应同步移动；缩放及空格平移后，延长线仍覆盖当前可见画布，刻度尺显示正常。
12. 使用白色、深灰色或红色区域较多的图片，确认选中与未选中的线条均可通过白色底描边辨认；切图、导出和模板保存不应包含画布外的延长显示或描边，切片数量与图片内布局一致。
13. 保持分割线模式，在最新竖线的虚线框内按住左键斜向拖动，确认仅左右移动，松开不新增线条；创建横线后重复操作，应仅上下移动。点击虚线框后直接松开也不新增线条；拖动后可一步撤销和重做。
14. 新建另一条线，确认虚线框转移到新线，旧线位置不会因再次拖动而改变；在新线框外操作仍按新建规则处理。缩放和平移后重复拖动，确认虚线框内均能命中，按住空格或鼠标中键仍优先平移画布。

图片旋转验收：

1. 导入方向明显的非正方形图片，在分割线、选择、拖动画布、自由画线和裁剪模式下，分别点击右下角“图片向右旋转 90°”，确认每次均顺时针旋转，宽高交换、图片重新适应画布，当前模式不变。
2. 添加横竖分割线、自由线和嵌套组，锁定部分对象并框选裁剪区域，再旋转图片。确认所有内容随图片同步旋转，横竖分割线互换，外延线仍清晰，组群结构、锁定和选择状态保留。
3. 每次旋转后撤销一次，应恢复图片、尺寸、线条和裁剪区域；重做一次恢复旋转结果。连续四次旋转后，应回到原来的方向和尺寸。
4. 旋转后继续添加、拖动分割线，检查坐标与刻度；导出 PNG、裁剪 PNG 和切图 ZIP，内容方向及尺寸应与当前图片一致。保存、套用及文件备份导入模板，也应恢复旋转后的布局。
5. 图片读取或旋转过程中，旋转按钮应禁用并显示处理状态；操作完成后恢复。未导入图片时不能触发旋转。

油漆桶与裁切标记验收：

1. 用横竖线分出多个矩形，按 B，设置颜色和不透明度，再点击两块区域；应仅标记点击的块，计数为 2。修改颜色后重填其中一块，计数仍为 2，不应半透明叠加变深。
2. 选择“清除标记”后点击已有标记，确认移除；Ctrl + Z 恢复，重做再次移除。右键应打开原菜单，空格临时拖动不应误标记。
3. 通过“导出 → 导出已标记区域”打开预览，确认只显示有效标记的区域数量，下载 ZIP 中每个区域对应一张原色 PNG，带孔或非矩形部分透明。清除最后一个标记后，该导出入口禁用，不应自动变成导出所有分区。
4. 测试斜线区域、带孔区域，以及标记与裁剪选区仅部分相交的情况；只有真实相交的部分可导出，外接矩形相交但多边形没有交集时不能生成空白图。
5. 保存并导出线条模板，确认文件不含图片、裁剪、区域标记或图片缩略图。改变当前标记后再套用模板，当前颜色、透明度和区域应保持不变；旋转图片后，标记随图旋转，撤销后恢复。旧模板迁移后只保留线条与分组。
6. 移动或删除原分割线，确认已有标记仍保留当时形状，清除模式仍能移除。套用到不同尺寸图片时，超出图片的标记隐藏且不导出；有标记但没有线条时替换图片，也应先确认。
7. 输入不完整 HEX 或清空不透明度后离开输入框，应恢复有效设置；100% 为不透明，0% 时应仍能看到标记轮廓。区域识别未完成或失败时不能使用旧结果标记，修改分割线后应重新识别。

现有自由画线等功能的回归验收：

1. 导入图片，按 L 手动画出三条线，按 V 返回选择工具。
   分别在选择工具和画线工具下拖动线身，确认两端同步移动、长度和角度不变；拖动端点应只调整该端，画线工具在空白处仍可新建线条。
   按 L 从图片外斜向拖过图片并在另一侧松开，确认线条沿拖动方向穿过图片、图片外不显示；完全在图片外画线不应新增对象。移动已有线条越过图片边界，确认超出部分隐藏，移回后恢复显示。
2. Shift 多选或框选线条，Ctrl + G 编组。
3. Ctrl + D 复制，拖到新位置；原组不应改变。
4. 再画线，将新线与组群再次编组，验证嵌套。
5. 双击进入组内，单独调整线条；Esc 返回上层。
6. 在属性面板镜像、旋转，再解组；解组瞬间线条不应跳动。
7. 锁定组群，确认不能移动或删除，再通过对象树解锁。
8. 逐步撤销与重做，确认每次拖动只占一步。
9. 按 C 框出选区并保存模板，刷新后先导入图片，再套用模板，检查线条层级和位置；模板不恢复原图或裁剪选区。无图片时确认不能套用模板。
10. 备份模板为文件，再导入；导出选区 PNG，确认尺寸及图像内容。
11. 让一条横线与图片左右边界相接，打开“导出 → 按线切图”，应得到两个区域；再加贯穿的竖线，应得到四个区域。
12. 用斜线连接图片两侧，检查斜切预览；单独画一条未连接边界的短线，不应多出切片。
13. 在图片内部画一个闭合四边形，应得到内部区域和带孔的外部区域；下载 ZIP，检查 PNG 的透明区域以及 `slices.json` 中的位置。
14. 改变裁剪选区，确认切图只处理选区；取消勾选部分切片后下载，ZIP 中应只包含所选图片及清单。
15. 切图计算或导出过程中关闭弹窗，确认不继续下载；重新打开可再次操作。
16. 导入另一张同尺寸图片，从模板列表“套用”，应保留新图并恢复线条结构；不同尺寸时应先提示，确认后不缩放自由线条，并保留当前裁剪选区和区域标记。检查 Tab 高度和留白，存储说明应始终位于模板面板底部。
17. 拖动选框上方的旋转柄，再撤销一次，应恢复拖动前角度；在画布右键复制、编组和镜像，结果应与侧栏操作一致。
18. 收起、展开对象面板；通过标识菜单返回首页，再进入编辑器，确认文档和撤销记录仍在。

## 本轮边界

已实现介绍首页和电脑端编辑器。移动端布局和触控手势尚未实现。

切图遵循实际线段，不自动延长端点。只有与图片边界或其他线段围成的区域才生成切片，短线不会凭空切开整图。有裁剪选区时只切该选区，锁定线条仍参与切图。预览最多处理 500 条线、200 个区域，单次勾选导出总包围盒面积不超过 8000 万像素，可分批勾选导出。

裁切标记最多保存 200 块、总轮廓顶点不超过 10 万个。标记不会随线条编辑或对象编组移动，只随整图旋转；标记相互重叠时，“清除标记”优先移除最上层，导出仍按各自形状分别生成图片。同一个标记与裁剪选区相交后即使分成多块，也保存在一张透明 PNG 中。

模板属于当前浏览器和站点地址，清理站点数据会删除本地模板，请通过模板文件备份。未保存的编辑内容不会在刷新后保留。

部署到静态服务器时，需要将 `/editor` 等前端路由回退到 `index.html`。当前开发服务器已支持此行为。

开发过程中未运行项目、构建、编译、语法检测或自动测试，需由使用者按以上命令和顺序验证。
